🌿 Project Summary

Natural Glow is a clean, modern, nature-themed skincare website built to meet every requirement of the IYF Final React + TailwindCSS project.
It replicates the LG desktop layout with pixel accuracy while featuring a unique brand identity, original content, and a warm, organic visual theme.

The website is fully responsive across SM, MD, and LG breakpoints.


🏷 Brand Identity

Brand Name: Natural Glow

Tagline: Where Pure Beauty Begins

Brand Voice: Calm · Feminine · Clean · Organic

Target Audience: People who prefer gentle, natural skincare products



🎨 Color System (Tailwind Config)
